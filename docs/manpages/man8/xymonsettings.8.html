NAME

xymonsettings.sh - show and change settings in xymonserver.cfg

 

SYNOPSIS

xymonsettings.sh [-c FILE] get NAME...
xymonsettings.sh [-c FILE] [-a] set NAME=VALUE...
xymonsettings.sh [-c FILE] [-w DIR] skins
xymonsettings.sh [-c FILE] [-w DIR] skin NAME
xymonsettings.sh [-c FILE] [-w DIR] animation on|off

 

DESCRIPTION

xymonsettings.sh reads and changes the settings in xymonserver.cfg(5) on an installed Xymon server, without opening the file in an editor, and switches the web pages between the installed icon sets.

get and set work with a value as a Xymon program sees it. In the file, a backslash escapes the next character, a "#" outside quotes starts a comment, and one pair of double quotes around the value is removed when it is loaded. get undoes that, and set adds the backslashes a value needs, so a value can hold double quotes, a "#" or a backslash as it is. A reference to another setting, such as "$XYMONSERVERWWWURL", is shown and written as it stands: the programs replace it when they load the file.

Programs read xymonserver.cfg when they start. After a set, xymongen(1) and the CGI programs use the new value at their next run; the programs that keep running, such as xymond(8) and its channel workers, use it once Xymon has been restarted.

 

COMMANDS

get NAME...
Print the value of each NAME, from the last line in the file that sets it, which is the one the programs use. With one NAME, only the value is printed; with more, one NAME=VALUE line for each. A NAME the file does not set is reported on stderr, and the exit status is then 1.

set NAME=VALUE...
Change each NAME to VALUE. Every line that sets NAME is rewritten: what stands before the name, such as "export ", and the comment after the value are kept, and every other line of the file stays as it is. The file is overwritten in place, so its owner, its mode and a symbolic link pointing to it are kept.

A NAME the file does not have yet is refused, so a misspelt name does not add a setting that nothing reads; use -a to add it. All assignments are checked before the file is changed: when one is refused, none is applied.

skins
List the icon sets ("skins") a skin command can choose, with the image type of each and "static" when it has a static variant, and mark the one XYMONSKIN points at with "*", noting when its static variant is in use. "classic" is the "gifs" directory in the web directory; every other name is a directory under "skins" there that has a green status icon.

skin NAME
Make the web pages use icon set NAME: set XYMONSKIN to "$XYMONSERVERWWWURL/gifs" for "classic", or to "$XYMONSERVERWWWURL/skins/NAME", and set IMAGEFILETYPE to the image type of its icons, the first of svg, png, gif and jpg that it has a green.TYPE in. INFOCOLUMNGIF, TRENDSCOLUMNGIF and CLIENTCOLUMNGIF are set to the skin's info.TYPE, trends.TYPE and clientlog.TYPE, or to green.TYPE for a column icon the skin does not have. A setting the file does not have yet is added. When the set in use is its static variant, NAME's static variant is chosen too; a set without one is used with its moving icons, and a warning says so.

animation on|off
Make the icons of the set in use move, or stand still: off points XYMONSKIN at the set's "static" directory, which has the same icons standing still, and on back at the set itself. Refused when XYMONSKIN points at none of the installed sets, or, for off, when the set has no static variant.

 

OPTIONS

-c FILE
The file to read and change. Default: $XYMONHOME/etc/xymonserver.cfg, the file xymon.sh starts Xymon with.

-a
With set: add a NAME the file does not have yet, as a new line at the end of the file.

-w DIR
With skins, skin and animation: the web directory that holds "gifs" and "skins". Default: XYMONWWWDIR from the settings file, as xymoncmd(1) expands it.

 

LIMITATIONS

Only the lines of the file itself are read and changed: a setting from a file it includes, and the "AREA/NAME=" and "NAME+=" forms, are left alone. A value cannot hold a newline.

 

EXAMPLES

xymonsettings.sh get XYMONSKIN
xymonsettings.sh set STATUSLIFETIME=60
xymonsettings.sh set XYMONPAGEACKFONT='COLOR="#33ebf4" SIZE="-1"'
xymonsettings.sh skins
xymonsettings.sh skin accessible
xymonsettings.sh animation off
